# Daily practice content

`{targetLanguage}/{level}/patterns.yml` and `vocab.yml`, loaded by `../dailyLoader.js`.
Each day `useDailyPractice` picks 3 patterns (due reviews first, at least 1 new) and 5 words (at least 2 new); new items come in file order, so put the most useful items first.

All example sentences are original. Pattern `match` lists lowercase substrings that must all appear for a sentence to count as using the pattern (used offline and when the AI check is unavailable); contractions and curly apostrophes are normalized.
